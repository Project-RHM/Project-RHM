# Tutorial

This tutorial builds up the language one idea at a time. Each chapter starts
from a complete file, says what is new in it, and shows what `rhema` makes of
it. The files are on the site exactly as the compiler checks them.

You need the `rhema` command (see [Install](../index.md#install)) and a text
editor. Make a directory to work in; nothing else is needed, because the
library grammars are found wherever you are.

1. [A first question](first.md): productions, attributes, the prompt and the
   answer.
2. [Difficulty is a budget](budget.md): inherited attributes, `when`,
   weights, spending exactly.
3. [Values and answers](values.md): randoms, lets, formulas, and why the
   answer is always right.
4. [Prompts, contexts, blanks](prompts.md): WeBWorK contexts and several
   parts in one question.
5. [Several questions in one file](questions.md): `question` blocks.
6. [Building on the library](import.md): `import` and arguments at the
   boundary.
7. [A whole assignment](sets.md): `set`, parts, budgets around a mean.
8. [Into WeBWorK](webwork.md): compiling, one paper per assignment,
   uploading.

!!! note "Notation"
    Commands are shown after a `$`. Output that depends on the paper drawn
    will differ from yours in its numbers, never in its shape.
